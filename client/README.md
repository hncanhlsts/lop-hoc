# 📱 Giao diện Web Học Sinh (Sẵn sàng cho GitHub Pages)

Dự án này là phần Giao diện Học sinh (Client Web) để xem bài giảng trực tiếp trên điện thoại/máy tính bảng khi **không có máy chiếu trong lớp học**.

---

### ✨ Các tính năng đã tích hợp:
1. **Tự động nhận Mã lớp**: Khi học sinh quét mã QR có link dạng `https://ten-ban.github.io/lop-hoc/?code=8899`, hệ thống sẽ tự động điền mã lớp.
2. **Thu phóng 2 ngón tay (Pinch-to-zoom & Pan)**: Học sinh có thể phóng to chữ nhỏ hoặc công thức toán học trên slide một cách mượt mà.
3. **Chế độ trải nghiệm mẫu (Demo Mode)**: Nhấn nút *"Trải nghiệm bài giảng mẫu"* để xem ngay 4 slide bài giảng mẫu và câu hỏi trắc nghiệm thử nghiệm mà chưa cần cài PowerPoint.
4. **Tương tác học sinh**: Giơ tay phát biểu, gửi phản hồi nhanh (Hiểu bài, Giảng chậm lại), tải ảnh slide về máy để ghi chép.
5. **Hộp câu hỏi trắc nghiệm (Quiz)**: Tự động trượt lên khi giáo viên kích hoạt câu hỏi (A, B, C, D).

---

### 🚀 Cách đưa lên GitHub Pages (Chỉ mất 2 phút, Miễn phí 100%)

1. **Bước 1**: Đăng nhập vào [GitHub.com](https://github.com) và tạo một Repository mới (ví dụ đặt tên là `lop-hoc` hoặc `class-slides`), chọn chế độ **Public**.
2. **Bước 2**: Tải toàn bộ các file trong thư mục `client/` này (`index.html`, thư mục `css`, `js`) lên nhánh `main`.
3. **Bước 3**: Vào **Settings** của Repository $\rightarrow$ Chọn mục **Pages** ở cột bên trái:
   - Tại mục **Branch**: Chọn `main` và thư mục `/ (root)`.
   - Bấm **Save**.
4. **Kết quả**: Sau khoảng 1 phút, GitHub sẽ cấp cho bạn một đường link miễn phí dạng:
   👉 `https://<ten-tai-khoan>.github.io/lop-hoc/`

---

### 💻 Cách chạy thử ngay trên máy tính hiện tại:
Bạn chỉ cần nhấp đúp trực tiếp vào file `index.html` trong thư mục `client` để mở trên trình duyệt Chrome / Edge / Cốc Cốc và trải nghiệm ngay!
